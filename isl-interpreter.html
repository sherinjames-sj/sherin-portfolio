🧏 isl interpreter

This one's still in the workshop

A real-time Indian Sign Language interpreter for mainstream classrooms: camera in, live captions out, no interpreter required to be in the room.

It's early. Right now this means dataset work on INCLUDE (around 4,300 videos across 263 ISL signs), landmark extraction with MediaPipe, and a first LSTM-based sequence model, not a finished tool yet.

Come back for updates, or check the Projects page for the current status.
